TM30 Bot v2 — วิธีติดตั้ง / อัปเดต

ติดตั้งครั้งแรก
1. แตกไฟล์ zip ไว้ในโฟลเดอร์ที่จะไม่ลบ เช่น C:\tm30-bot
2. เปิด Chrome พิมพ์ chrome://extensions
3. เปิดสวิตช์ "Developer mode" มุมขวาบน
4. กด "Load unpacked" แล้วเลือกโฟลเดอร์ tm30-bot (โฟลเดอร์ที่มี manifest.json)

อัปเดตจากรุ่นเดิม
1. แตก zip ทับโฟลเดอร์เดิม
2. ที่ chrome://extensions กดปุ่มลูกศรวน (Reload) ที่การ์ด TM30 Bot
3. Chrome จะขอสิทธิ์เพิ่มสำหรับ tm7.toyka.net ให้กดยอมรับ
4. กด F5 ที่แท็บเว็บ TM30

ใช้เองที่เครื่อง (เหมือนรุ่นแรก)
① เลือกไฟล์ Excel แล้วอัปโหลด → ตรวจรายชื่อ → กด "ยืนยันบันทึก" → บอทโหลด PDF ต่อ
② ดาวน์โหลด PDF: ติ๊กช่องหน้าชื่อ = เฉพาะคนที่ติ๊ก / ไม่ติ๊ก = ทุกคนในผลค้นหา

รับงานจาก toyka (สั่งจากมือถือหรือจากหน้า /today)
1. Chrome เครื่องนี้ต้อง login tm7.toyka.net ด้วย Google ไว้ก่อน
2. เปิดเว็บ TM30 แล้ว login เอง เปิดแท็บนี้ค้างไว้
3. ติ๊ก "รับงานจาก toyka" ในกล่องบอท จนขึ้น "เชื่อม toyka แล้ว · รองาน"
4. ที่หน้า /today กด "🤖 ส่งเข้า TM30 (บอท)"
5. บอทอัป Excel แล้วหยุดรอ หน้า /today จะขึ้นรายชื่อให้ตรวจ กด "✅ ยืนยันบันทึกเข้า TM30"
6. บอทบันทึก โหลดใบรับแจ้งทีละคน แล้วส่งขึ้นการ์ดของแต่ละคนใน /today

ถ้าจะออกนอกบ้าน
- ตั้ง Windows ไม่ให้ sleep และเปิดแท็บ TM30 ค้างไว้ในหน้าต่างที่ไม่ย่อ
- ถ้า login TM30 หมดอายุ หน้า /today จะขึ้น "ยังไม่เห็นบอท" ต้องรีโมตเข้ามา login ใหม่
