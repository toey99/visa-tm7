# tm7.toyka.net

All-office daily board for 30-day extension cases (Bangkok / Nonthaburi / Rayong / Chiang Saen).

- `/today` — drop a day's LINE photos, auto-group per person, TM.7 packets per office, TM.30 Excel, white-background photos, A4 photo sheet, one-page summary, folder zip, bills.
- `/single` — the original one-person Bangkok form.

Env: `GEMINI_API_KEY`, `OPENAI_API_KEY`, `AUTH_SECRET`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `AUTH_ALLOWED_EMAILS` (comma-separated).
